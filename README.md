# ORBIT Insurance Platform

**O**nline **R**ecommendation for **B**enefits, **I**nsurance & **T**erms

An AI-powered web system that recommends personalized insurance plans using machine learning. Based on user inputs like age, budget, and salary, it suggests suitable coverage, estimates premiums, compares plans, and generates digital policies.

## Features

- ✅ **User Authentication** - Secure login/signup using email or Google OAuth
- 🤖 **AI-Powered Recommendations** - Machine learning-based personalized insurance plan suggestions
- 💰 **Premium Estimation** - Dynamic premium calculation based on user profile
- ⚖️ **Plan Comparison** - Side-by-side comparison of multiple insurance plans
- 📱 **Responsive Design** - Fully functional on desktop, tablet, and mobile devices
- 📄 **PDF Generation** - Downloadable policy documents
- 🏢 **10+ Insurance Providers** - Coverage from major Indian insurance companies
